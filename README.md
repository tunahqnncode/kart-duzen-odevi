Four Card Feature Section
Bu proje, Frontend Mentor üzerinde yer alan Four Card Feature Section meydan okumasını (challenge) tamamlamak için geliştirilmiştir.

🚀 Proje Hakkında
Bu çalışmada, CSS Grid kullanarak modern ve esnek bir kart yerleşimi (layout) yapısı oluşturulmuştur. Farklı renk şeritlerine sahip kartlar, hafif gölgelendirmeler ve responsive (duyarlı) bir düzen içermektedir.

🛠️ Kullanılan Teknolojiler
HTML5 - Sayfa iskeleti ve semantik etiketler

CSS3 - Stil giydirme, Flexbox ve CSS Grid yerleşim sistemi

Git & GitHub - Versiyon kontrolü ve kod yönetimi

📌 Öne Çıkan Özellikler
CSS Grid kullanılarak oluşturulan özel zikzak/merdiven kart yerleşimi.

Her karta özel renkli üst şeritler (border-top).

Modern kutu gölgeleri (box-shadow) ve yuvarlatılmış köşe tasarımları (border-radius).

Temiz ve düzenli klasör/kod yapısı.
